Open HACS → Integrations → **Custom repositories**2. Add `https://github.com/TSOrest/powerbot-s-ha` as type **Integration**3. Find **Samsung POWERbot-S** and click **Download**4. Restart Home Assistant5. Go to **Settings → Devices & Services → Add Integration → Samsung POWERbot-S**### Manual Installation1. Copy the `custom_components/powerbot_s/` folder to your HA `config/custom_components/` directory2. Restart Home Assistant3. Add the integration via the UI### Finding Your Device ID1. Open the **POWERbot-S** app2. Go to the robot's **Settings → Device Info**3.
